# 動作幀（綠幕去背 + 自動對齊）

`sheet.png` 是六格橫向排列的 sprite sheet，每格 270×315 px，
規格寫在 `frames.json`（格數、格寬高、錨點座標）。

| 格 | 動作 | 備註 |
|---|---|---|
| 0 | idle | 站立持劍 |
| 1 | walk1 | 走路 A |
| 2 | walk2 | 走路 B |
| 3 | jump | 跳躍（腳離地 51px，已保留） |
| 4 | atk_up | 舉劍過頭 |
| 5 | atk_thrust | 前刺 |

## 品質量測（自動）

- 走路三幀身高 250～251 px，**差 1%**
- 腳底線 y=504～506，**差 2 px**
- 以頭部質心對齊後，頭與軀幹輪廓重合，只有腿與披風在動

## 產生方式

```bash
python3 tools/greenscreen_sheet.py 綠幕圖.jpg assets/character/anim idle walk1 walk2 jump atk_up atk_thrust
```

腳本會自動去背、以**連通區域**切出每個姿勢、對齊、輸出並驗證有沒有被裁切。

> ⚠️ 切圖一定要用連通區域，不能用垂直中線。角色的披風往左伸、劍往右伸，
> 中線切法會同時「切掉自己的披風」與「切進隔壁角色的劍」——第一版就踩到這個坑。

## 對位方式

`frames.json` 的 `anchor` 記錄了腳底與頭部中心在畫格內的座標。
遊戲繪製時把 anchor 對到角色座標即可，不需要每格微調。

## 還缺的動作

`fall`（下墜）、`hurt`（受傷）、`sit_cry`（坐地哭，倒地演出用）。
補圖時務必沿用同一組規則：綠幕、側面朝右、全身不裁切、
**所有姿勢同比例同地平線**。
