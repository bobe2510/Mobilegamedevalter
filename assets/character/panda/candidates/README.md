# 熊貓娃娃 · 定裝圖候選

Qwen-Image-3.0，同一份 prompt、六個 seed，共 US$0.18。
`_contact-sheet.jpg` 是六張並排的對照表。

**挑一張之後**，把它存成 `assets/character/panda/REFERENCE.png`，
之後所有熊貓的動作圖都以它為準（`tools/gen_sprites.py`）。

挑的時候看這幾點：

| 看什麼 | 為什麼 |
|---|---|
| **側面的嘴型清不清楚** | 遊戲裡只會看到側面，縮到 70px 時側臉全靠它 |
| 黑白分界是否乾淨 | 色塊分明才撐得住縮小 |
| 身形圓不圓 | 要讀得出「布偶」而不是「真熊貓」 |
| 藍蝴蝶結的大小 | 要跟大臣法杖上那隻小熊貓對得上 |

設定上牠有兩種型態，定裝圖先定**站姿**：

- **站姿**：跟在公主身邊的跟班、會講話（遊戲內的點陣跟班就是這個）
- **四足**：戰敗時拉熊貓車（現有的 `assets/cart.png` 是這個樣子）
