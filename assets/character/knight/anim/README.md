# 角色動作幀（綠幕去背 + 自動對齊）

`sheet.png` 是十格橫向排列的 sprite sheet，規格寫在 `frames.json`。

| 格 | 動作 | 站姿身高 | 備註 |
|---|---|---|---|
| 0 | idle | 251 px | 站立持劍 |
| 1 | walk1 | 251 px | 走路 A |
| 2 | walk2 | 250 px | 走路 B |
| 3 | jump | — | 空中（錨點用虛擬地面推算） |
| 4 | atk_up | — | 舉劍過頭 |
| 5 | atk_thrust | — | 前刺 |
| 6 | fall | — | 下墜（空中） |
| 7 | hurt | — | 受擊後仰（空中） |
| 8 | sit_cry | — | 坐地哭泣，含掉在旁邊的劍 |
| 9 | victory | 251 px | 舉劍歡呼 |

## 產生方式

```bash
python3 tools/build_character.py
```

來源是兩張綠幕圖（六格 + 四格）。第二張的角色比第一張大 74%，
腳本會以**站姿參考幀**的身高自動統一比例（第二批縮放 0.574）。

單張綠幕圖也可以單獨處理：

```bash
python3 tools/greenscreen_sheet.py 綠幕圖.jpg 輸出資料夾 名稱... [--air 空中姿勢名稱]
```

## 踩過的坑（改圖前先看這段）

1. **切圖要用連通區域，不能用垂直中線。**
   披風往左伸、劍往右伸，中線會同時切掉自己的披風、又切進隔壁的劍。
2. **落單的區塊要併回角色。**
   哭泣那格的劍是掉在地上、和角色分離的，會被當成獨立區塊。
   腳本會自動把小區塊併入最近的角色。
3. **空中姿勢的錨點不是頭頂，是「虛擬地面」。**
   用「頭頂 + 站姿身高」推算，這樣每一格的錨點都落在同一個語意位置（腳下的地面），
   遊戲繪製時才不用逐格微調。
4. 每次產生都會驗證每格像素數與原圖區塊是否一致，被裁切會直接報錯。

## 補圖時的要求

綠幕、側面朝右、全身不裁切、**所有站立姿勢同比例同地平線**、不要地面陰影與文字。
不同批次的整體大小可以不同（腳本會統一），但**同一張圖裡必須一致**。
