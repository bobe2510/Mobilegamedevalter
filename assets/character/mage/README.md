# 魔法大臣（中等難度可玩角色）

黑髮藍色系的魔女，外型參考《魔女之旅》伊蕾娜。設定與玩法見 [`/DESIGN.md`](../../../DESIGN.md)。

| 檔案 | 內容 |
|---|---|
| `portrait.jpg` | 全身立繪（784×1168），對話／選角畫面用 |
| `turnaround/*.png` | 五個角度的轉身圖（正面／正面斜角／側面／背面斜角／背面） |
| `anim/sheet.png` | 十格側面動作，規格見 `anim/frames.json` |

## 動作幀

frame key 與小公主**完全相同**，所以換角色只要換 sheet 路徑，程式不用改：

| key | 小公主 | 魔法大臣 |
|---|---|---|
| `idle` / `walk1` / `walk2` / `jump` / `fall` | 一樣 | 一樣 |
| `atk_up` | 舉劍過頭 | 舉杖蓄力 |
| `atk_thrust` | 前刺 | **揮杖射出魔法飛彈**（飛彈已含在該格） |
| `hurt` | 受擊後仰 | 受擊後仰 |
| `sit_cry` | 坐地哭泣 | **跪地撐杖**（單手握杖、單手扶地、閉眼） |
| `victory` | 舉劍歡呼 | 舉杖歡呼 |

站姿身高 230 px（小公主是 251 px），`frames.json` 的 `stand_h` 有記錄，
遊戲端依這個值換算成畫面尺寸即可。

## 產生方式

```bash
python3 tools/build_character.py mage
```

來源是兩張綠幕圖（六格 + 四格）。第二張的角色比第一張大 68%，腳本會自動統一比例。
施法那格的魔法飛彈與法杖是分離的區塊，腳本會自動併回角色。
