# 角色立繪（綠幕去背後的乾淨素材）

來源是一張綠幕轉身圖，已經去背 + 去綠邊，存成透明 PNG。
**目前遊戲沒有讀取這個資料夾**，是保留素材。

| 檔案 | 姿勢 | 適合用在 |
|---|---|---|
| `front.png` | 正面站姿 | 對話立繪、開場劇情 |
| `front3q.png` | 正面斜角、開口說話 | 標題畫面角色、對話立繪 |
| `side.png` | **側面持劍走姿** | **橫向捲軸遊戲內角色（骨架動畫的基底）** |
| `back3q.png` | 背面斜角 | 過場（走向遠方） |
| `back.png` | 背面 | 過場 |

- 五張都是同一比例，角色高度 302～305 px（差異 1%）
- 半透明邊緣只佔 1%，去背乾淨、沒有綠邊
- 遊戲內若要用，建議縮到 180 px 高左右（約 26 KB／張）

## 如果要做骨架動畫

`side.png` 可切成 6 個零件：頭（含馬尾）、披風、持劍手臂、身體、前腳、後腳。
切件時要沿輪廓做遮罩（用顏色判斷會把披風的金邊切掉），
被手臂擋住的身體區域需要補繪一小塊。
