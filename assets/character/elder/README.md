# 長公主（困難難度可玩角色）

帝國首席騎士團長，小公主的姐姐。白金鎧＋紅披風，金髮高馬尾、**紅瞳**，武器是大劍。
設定與玩法見 [`/DESIGN.md`](../../../DESIGN.md)。

| 檔案 | 內容 |
|---|---|
| `portrait.jpg` | 全身立繪（784×1168） |
| `turnaround/*.png` | 五個角度的轉身圖 |
| `anim/sheet.png` | 十格側面動作，規格見 `anim/frames.json` |

## 動作幀

frame key 與小公主、魔法大臣完全相同：

| key | 長公主 |
|---|---|
| `atk_up` | 舉劍蓄力，**已含金色斬擊特效** |
| `atk_thrust` | 橫掃，**已含金色弧形斬擊特效** |
| `sit_cry` | **兩手握劍插地撐著**，不甘心地喘氣（閉眼） |
| `victory` | 舉劍，自信的笑 |

站姿身高 245 px（小公主 251、大臣 230）。

> ⚠️ 她的攻擊幀**自帶斬擊特效**，接進遊戲時要把程式畫的劍光弧線關掉或減弱，
> 否則會疊成兩層。

## 產生方式

```bash
python3 tools/build_character.py elder
```

處理過程中自動解決了兩件事：
- 六格圖的金色斬擊特效有三小塊與本體分離，自動併回施法那格
- 轉身圖有兩個角色的劍相連成一塊，工具自動從最窄的欄位切開
