## 場景一：初遇（王宮花園）　→ `cg/knight/open-3.jpg`

公主帶著劍溜出寢宮，在花園裡撞見一隻站著的熊貓娃娃。

> **熊貓**：「仁慈的騎士啊——能否聽聽您忠誠臣民的困擾？」

公主的心理活動（建議一句一句跳出來，每句停頓後再接下一句）：

1. 「……這是什麼？」
2. 「玩偶……熊？」
3. 「為什麼玩偶熊會講話？」
4. 「怎麼辦，是陷阱嗎……？」
5. 「可是這個，超可愛的。」
6. 「……還是聽一下好了。」

演出重點：**臉紅 + 混亂 + 動搖**。她想端出騎士的威嚴，但完全被可愛度擊潰——
跟後面「輸了就哭哭」是同一條反差軸線。

### 之後可以接的橋段（尚未定稿）

- 熊貓自稱是「忠誠的臣民」，請求騎士大人陪它出門解決一點小麻煩
  （實際上是魔法大臣的說詞，目的是跟在公主身邊保護她）。
- 公主一口答應，覺得自己終於有了第一位追隨者。
- 從頭到尾她都不知道熊貓是大臣的傀儡。
